# tcgStock · iOS 风格交互设计稿 v7

打开 [index.html](./index.html) 查看。当前交互稿含 16 个可点击页面，桌面端可在「交互预览」与「全部页面」之间切换。本次交付的独立副本保存在 `ios27-v7-rifthunt/`。

## 当前规则

- 首版仅 Riftbound 美区英文卡牌、USD、RiftHunt 日级参考价。多模拟账户各自保存资金、持仓、交易和充值记录。新账户从 $0 开始。
- 以当前日级市场价模拟交易；买卖均按成交额 2.5% 收取手续费，每笔最低 $0.30。北京时间 07:00—23:00 可交易。
- 不展示没有可信历史数据的个卡价格走势图、模拟指数或跨渠道比价。资产分析展示总收益率与累计盈亏，日线和周线从实际观察到的账户估值逐步积累，不补造未访问日期。
- 设计稿内的 5 张示例卡图放在 `assets/`，不依赖远程图片请求。设计稿用固定示例数据；项目根目录的 React HTML 版本请求 RiftHunt 批量数据并在本地缓存卡图。

## 页面

选择 TCG、账户、充值、行情、自选、搜索、个卡详情、下单、确认、回执、资产分析、账户记录、设置、分享、缺价、休市状态。
